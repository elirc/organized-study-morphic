# Technology Best Practices

This suite teaches how Morphic uses its main technologies in real code. It is not a generic React or Next.js guide. Every major pattern points back to files in this repo.

Use it one technology at a time:

1. Read `01-technology-map.md`.
2. Pick one technology.
3. Read its examples in `02-real-code-patterns.md`.
4. Study the larger lesson in `03-cross-cutting-engineering-lessons.md`.
5. Practice with the 30-day plan in `04-practice-plan.md`.

## Difference From The Architecture Suite

The architecture suite follows the system. This suite follows the tools: React, TypeScript, Next.js, AI SDK, Drizzle, Supabase, Zod, Tailwind/shadcn, Vitest, Docker/config, Redis/search.

## Turning Patterns Into Practice

For each pattern, ask:

- What responsibility does this technology own here?
- What boundary does it protect?
- What would go wrong if I copied it incorrectly?
- What test would prove it works?
