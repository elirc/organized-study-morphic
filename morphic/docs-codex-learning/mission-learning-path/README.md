# Mission Learning Path

This suite turns Morphic into a structured training campaign. Each mission asks you to trace, annotate, answer, review, or debug a real path in the repo. The goal is engineering judgment: knowing where to look, what to distrust, and how to explain behavior under pressure.

## How The Mission System Works

Every mission includes a concept, design intent, exact files, an aha moment, Socratic questions, self-grading guidance, and the next missions it prepares you for. Do not only read. Open the files, write answers, then compare your answer to the rubric.

## Recommended Pacing

- Tier 1: 1 mission per day.
- Tier 2: 2-3 missions per week.
- Tier 3: 1 mission per week, with written notes.

## Using Codex Without Losing The Learning

Ask for hints, not solutions:

```text
I am on Mission 7. Ask me questions that help me trace the data flow. Give one hint at a time. Do not summarize the full answer until I try.
```

If you ask Codex to explain a file, first write your own summary. Then ask Codex to critique your summary against the code.
