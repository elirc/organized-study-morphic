# 04 — Code Reading Gym

Reading code is a trainable skill with reps, not osmosis. Four stations:

| File | Rep type | Time per rep |
| --- | --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | Annotate real excerpts: inputs, outputs, invariants, side effects, failure modes | 15–25 min |
| [02-trace-tables.md](02-trace-tables.md) | Follow a value through layers, step by step | 20–30 min |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | Bad-vs-better pairs tied to real repo patterns | 10 min |
| [04-review-katas.md](04-review-katas.md) | Review fake PRs; findings graded blocking/important/optional | 25–40 min |

Rules: write your answers down **before** reading the provided ones — reading answers feels like learning and isn't. Grade yourself with the rubrics. Two stations per week is a sustainable pace; katas are the best interview prep per minute (code-review rounds are increasingly standard for mid-level loops — see [08-interview-prep/05](../08-interview-prep/05-debugging-and-code-review-rounds.md)).
