## How mid-level loops are usually structured

1. **Recruiter/screen** — motivation, basics.
2. **Technical phone screen** — 1–2 focused coding problems + language questions.
3. **Practical coding** — build/extend something; often a small feature or bug fix.
4. **System design** — "design X" (mid-level: one service well; senior: scale/tradeoffs).
5. **Behavioral** — STAR stories: conflict, ambiguity, mistake, tradeoff, leadership.

You have a real codebase to draw on for every one of these — that's what this module operationalizes.

## The golden rule

Answer with a **concrete example, a tradeoff, and a failure mode** — never a definition alone.

- Junior: defines the term.
- Mid: defines it, gives a real example, names one tradeoff.
- Senior: adds the invariant/alternative design/when-the-standard-answer-is-wrong.

Every card below shows all three so you can hear the gap and climb it.

## How to practice a card

Read the question, cover the answers, say your answer aloud in 90 seconds, *then* compare. Say it aloud — silent reading hides the gaps that a live interview exposes. Trace the anchor before answering the anchored ones. Two-week schedule: [07-two-week-cram-plan.md](07-two-week-cram-plan.md).
