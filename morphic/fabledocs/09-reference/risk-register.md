## How to use this

- **Contributors:** R5, R7, R2 are the best value-to-effort (mid-level tickets M1, M3, M4). R3, R4, R6 need investigation before code — write the design note first.
- **Reviewers:** this is your "does the PR touch a known-risky area?" list.
- **Interview prep:** R2/R3/R4/R6 are ready-made "tell me about a risk you found" stories ([08-interview-prep/06](../08-interview-prep/06-behavioral-star-stories.md)), *if* you frame the investigate-ones honestly as "possible risk, would verify".

**Reminder:** none of these were exploited or reproduced against a running instance (no DB/keys on the authoring machine). Treat *investigate* rows as hypotheses to verify, not confirmed vulnerabilities. See [verification-log.md](verification-log.md).
